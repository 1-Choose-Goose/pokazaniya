# Мои показания

Запуск: откройте `main.py` в PyCharm и нажмите **Run**. Нужен Python 3.11 или новее. Для экспорта в Excel установите `openpyxl` в выбранный интерпретатор PyCharm: `python -m pip install openpyxl`. Остальные функции работают без внешних библиотек.

На одном экране расположены шесть разделов: **Вода**, **Отопление**, **Электроэнергия**, **Газ**, **ТКО**, **Домофон**. Номера и даты счётчиков задаются один раз кнопкой **Номера счётчиков**. В формах видны последние три цифры номера и дата; полный номер сохраняется в истории. Для воды вводятся ХВС и ГВС; общее воды считается автоматически. Для электроэнергии вводятся показания дня и ночи. Для газа номер и показание необязательны. Заполненные разделы сохраняются одной кнопкой **Сохранить** под таблицей.

В пустых полях показаний серым цветом показывается прогноз по среднему месячному расходу. Он рассчитывается по предыдущим записям и выбранной дате. Прогноз — только подсказка: он не попадает в базу, пока вы сами не введёте показание. Для прогноза нужны как минимум две предыдущие записи по этому счётчику.

Отметка **Оплачено** связана с датой и временем оплаты по чеку. Сегодняшняя дата подставляется автоматически, её можно изменить вручную или кнопкой календаря. Часы и минуты нужно указать самостоятельно: принимаются `12:55`, `12.55` и `12,55`; в истории время показывается как `12:55`. Дата показаний и период выбираются таким же календарём без времени. История сгруппирована по месяцам выбранного года. В каждом месяце показаны все шесть услуг: незаполненные и неоплаченные строки выделены красным. В строке месяца видна общая оплаченная сумма за этот месяц; сверху — сумма за год. Отдельные колонки даты показаний и номера счётчика в таблице скрыты. Для заполнения пустой строки выберите её и нажмите **Изменить**.

Данные хранятся рядом с программой в `pokazaniya.db`. Старая база из предыдущей версии переносится автоматически при первом запуске; старые таблицы сохраняются. Для резервной копии скопируйте этот файл. Внизу окна доступны экспорт CSV и оформленный экспорт Excel: сводка по месяцам, полный журнал и настройки счётчиков. Иконки окон и панели задач хранятся в `app_icon.png` и `app_icon.ico` рядом с `main.py`; их исходник — `app_icon.svg`.

Горячие клавиши:

- `Ctrl+1` … `Ctrl+6` — перейти к разделу;
- `Ctrl+S` или `Ctrl+Enter` — сохранить открытую форму;
- `Ctrl+F` — перейти к истории;
- `F2` — изменить выбранную запись;
- `Delete` — удалить выбранную запись в истории;
- `Esc` — очистить открытую форму;
- `Ctrl+←` и `Ctrl+→` — сменить год;
- `Ctrl+E` — экспорт Excel;
- `Ctrl+M` — номера счётчиков;
- `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A` — копировать, вставить, вырезать, выделить всё;
- `F1` — показать список клавиш.

В полях ввода также работает меню правой кнопкой мыши. Числа принимают точку или запятую; дата показаний и расчётный период вводятся в формате `ДД.ММ.ГГГГ`.
