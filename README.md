# Мои показания

## Обновления программы

Собранная Windows-версия автоматически проверяет новые выпуски через GitHub Releases
через 2,5 секунды после запуска. Текущая версия показана кнопкой в правой части
заголовка; этой же кнопкой можно запустить ручную проверку. Найденное обновление
скачивается в фоне, проверяется по SHA-256, после подтверждения программа закрывается,
атомарно заменяет свои файлы и запускается снова. Во время установки сохраняются
`pokazaniya.db`, `yandex-disk.json` и папка `.yandex-sync`; при ошибке установщик
возвращает предыдущую версию.

Номер версии задаётся в `version.py`. Для локальной сборки релиза выполните
`powershell -ExecutionPolicy Bypass -File .\build-release.ps1`. Готовая папка появится
в `dist\Pokazaniya`. Публикация тега вида `v1.0.1`, совпадающего с `APP_VERSION`,
запускает `.github/workflows/release-windows.yml`: workflow тестирует проект, собирает
`Pokazaniya-Windows-x64.zip` и публикует его в GitHub Release. Именно это имя архива
ожидает встроенный клиент обновлений. Репозиторий релизов должен оставаться публичным:
GitHub не отдаёт приватные Releases приложению без пользовательской авторизации, а
встраивать личный токен в распространяемый `.exe` небезопасно.

## Яндекс Диск

После подключения программа автоматически отправляет сохранённые изменения на Диск
в `MyDate/Показания/pokazaniya.db`. На Диске всегда один файл: новая база загружается
с перезаписью, без предварительного удаления старой. Временный согласованный снимок
SQLite удаляется после отправки. Отдельного архива программа не создаёт.

Отправка начинается сразу после успешного нажатия кнопки **Сохранить** (в том числе
при сохранении номеров счётчиков). Запуск программы, просмотр истории и закрытие
сами по себе отправку не запускают. Статус и время последней подтверждённой отправки
видны сверху. При отсутствии интернета данные остаются локально; для новой попытки
нажмите **Сохранить** ещё раз или выберите **Проверить и отправить сейчас**. Если
отправка уже началась, при закрытии программа дождётся её завершения.

Кнопка **Яндекс Диск** позволяет подключить аккаунт, повторить отправку или восстановить
базу. Если облачный файл отличается от ранее отправленного, автоматическая перезапись
останавливается: можно восстановить облачную версию либо явно заменить её локальной.
Это не система одновременной работы на двух компьютерах: перед переходом на другой
компьютер дождитесь отправки, закройте программу, затем восстановите актуальную базу.
Проверка различий не исключает гонку при одновременном редактировании.

### Перенос на другой компьютер

1. Дождитесь статуса «На Диске» и закройте программу.
2. Скопируйте папку программы вместе с `main.py`, `yandex_sync.py`, картинками,
   `pokazaniya.db`, `yandex-disk.json` и папкой `.yandex-sync`.
3. Установите Python 3.11+ и зависимости: `python -m pip install -r requirements.txt`.
   Старую папку `.venv` переносить не нужно. Запустите `python main.py`.

**Повторная авторизация не нужна**, если перенесён `yandex-disk.json` и токен ещё действителен.
По вашему выбору токен хранится в этом файле обычным текстом, без шифрования. Не размещайте
этот файл в публичном доступе: он даёт доступ на чтение и запись Диска. Файл исключён из Git.
Если токен отсутствует, отозван или истёк, нажмите **Подключить / сменить аккаунт**,
войдите на странице Яндекса и вставьте выданный токен в окно программы.

Если локальной базы нет, при запуске программа предложит скачать её с Диска **до создания
новой базы**. При восстановлении существующей базы потребуется подтверждение замены.
Удалённые внутри программы записи также исчезают из облачного файла после отправки.

Запуск: откройте `main.py` в PyCharm и нажмите **Run**. Нужен Python 3.11 или новее.
Для экспорта в Excel установите `openpyxl` в выбранный интерпретатор PyCharm:
`python -m pip install openpyxl`. Остальные функции работают без внешних библиотек.

На одном экране расположены семь разделов: **Вода**, **Отопление**, **Электроэнергия**, **Газ**, **ТКО**, **Домофон**, **Домашний интернет**. Номера и даты счётчиков задаются один раз кнопкой **Номера счётчиков**. В формах видны последние три цифры номера и дата; полный номер сохраняется в истории. Для воды вводятся ХВС и ГВС; общее воды считается автоматически. Для электроэнергии вводятся показания дня и ночи. Для газа номер и показание необязательны. Заполненные разделы сохраняются одной кнопкой **Сохранить** под таблицей.

Для газа допускается одна запись на календарный месяц. Повторное сохранение за тот же месяц блокируется; существующую запись нужно выбрать в истории и открыть кнопкой **Изменить**. Полностью одинаковые повторные записи других услуг также не добавляются.

В пустых полях показаний серым цветом показывается прогноз по среднему месячному расходу. Он рассчитывается по предыдущим записям и выбранной дате. Прогноз — только подсказка: он не попадает в базу, пока вы сами не введёте показание. Для прогноза нужны как минимум две предыдущие записи по этому счётчику.

Отметка **Оплачено** связана с датой и временем оплаты по чеку. Сегодняшняя дата подставляется автоматически, её можно изменить вручную или кнопкой календаря. Часы и минуты нужно указать самостоятельно: принимаются `12:55`, `12.55` и `12,55`; в истории время показывается как `12:55`. Дата показаний и период выбираются таким же календарём без времени. История сгруппирована по месяцам выбранного года. В каждом месяце показаны все семь услуг: незаполненные и неоплаченные строки выделены красным. В строке месяца видна общая оплаченная сумма за этот месяц; сверху — сумма за год. Отдельные колонки даты показаний и номера счётчика в таблице скрыты. Для заполнения пустой строки выберите её и нажмите **Изменить**.

Данные хранятся рядом с программой в `pokazaniya.db`. Старая база из предыдущей версии переносится автоматически при первом запуске; старые таблицы сохраняются. Для резервной копии скопируйте этот файл. Внизу окна доступны экспорт CSV и оформленный экспорт Excel: сводка по месяцам, полный журнал и настройки счётчиков. Иконки окон и панели задач хранятся в `app_icon.png` и `app_icon.ico` рядом с `main.py`; их исходник — `app_icon.svg`.

Горячие клавиши:

- `Ctrl+1` … `Ctrl+7` — перейти к разделу;
- `Ctrl+S` или `Ctrl+Enter` — сохранить открытую форму;
- `Ctrl+F` — перейти к истории;
- `F2` — изменить выбранную запись;
- `Delete` — удалить выбранную запись в истории;
- `Esc` — очистить открытую форму;
- `Ctrl+←` и `Ctrl+→` — сменить год;
- `Ctrl+E` — экспорт Excel;
- `Ctrl+M` — номера счётчиков;
- `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A` — копировать, вставить, вырезать, выделить всё;
- `F1` — показать список клавиш.

В полях ввода также работает меню правой кнопкой мыши. Числа принимают точку или запятую; дата показаний и расчётный период вводятся в формате `ДД.ММ.ГГГГ`.
